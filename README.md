# GAS Tweet Archive

X(Twitter) のデータアーカイブ（tweet.js / bookmark.js）を Google スプレッドシートにインポートし、ダッシュボードで可視化・分析するツール。

## できること

| 機能 | 説明 |
|:---|:---|
| 📥 tweet.js インポート | Twitterデータアーカイブの全ツイート履歴をスプレッドシートに取り込む |
| 🔖 bookmark.js インポート | ブックマーク一覧を取り込み、カテゴリ分け・整理できる |
| 📊 ダッシュボード表示 | 月間投稿トレンド、いいねランキング、ツイート種別構成をグラフで可視化 |
| 🌡️ 時間帯ヒートマップ | いつツイートする傾向があるかを曜日×時間帯で色分け表示 |
| 🔍 検索・フィルター | キーワード検索、種別フィルター、いいね数ソート |

## 必要環境

- Google アカウント（無料）
- X(Twitter) のデータアーカイブ（設定 → データのダウンロード）

## 使い方

1. Xの設定からデータアーカイブをダウンロード（zip形式）
2. 解凍して `tweet.js` / `bookmark.js` を取り出す
3. Google スプレッドシートを開く（初回はテンプレートをコピー）
4. メニュー → 「📥 データをインポート」
5. ファイルを選択 → インポート開始
6. 自動でダッシュボードが生成される 🎉

## 開発

```
npm install        # 依存関係インストール
npm test           # テスト実行
npm run build      # TypeScript コンパイル
npm run deploy     # GAS にデプロイ
```
