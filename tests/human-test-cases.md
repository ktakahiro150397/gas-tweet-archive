/**
 * 人間が手動テストするケース一覧
 *
 * 以下のテストケースは自動テストではカバーできないため、
 * 実際のGoogleスプレッドシート環境で人間がテストする必要があります。
 *
 * ============================================================
 * テスト前準備
 * ============================================================
 * 1. GASプロジェクトを Google Apps Script にデプロイする
 * 2. テスト用の新しいスプレッドシートを作成する
 * 3. テスト用の tweet.js / bookmark.js を準備する（実データ or サンプル）
 *
 * ============================================================
 * テストケース
 * ============================================================
 */

/**
 * 【TC-01】メニュー表示
 * 1. スプレッドシートを開く
 * 2. メニューバーに「📊 X Archive Tools」が表示されていることを確認
 * 3. プルダウンに以下が含まれることを確認:
 *    - 📥 データをインポート
 *    - 🔄 ダッシュボード更新
 *    - 📖 使い方ガイド表示
 *    - ℹ️ バージョン情報
 * 期待結果: 全てのメニュー項目が表示される
 */

/**
 * 【TC-02】ファイルアップロードダイアログ
 * 1. メニュー → 「📥 データをインポート」をクリック
 * 2. モーダルダイアログが表示されることを確認
 * 3. ダイアログに以下が含まれることを確認:
 *    - ファイル選択ボタン（accept: .js, .json）
 *    - 「インポート開始」ボタン
 *    - 対応ファイル形式の説明
 * 期待結果: ダイアログが正しく表示される
 */

/**
 * 【TC-03】tweet.js インポート（正常系）
 * 1. 実際のXデータアーカイブから tweet.js を準備する（1,000件以上推奨）
 * 2. メニュー → インポート → ファイルを選択 → インポート開始
 * 3. プログレスToastが表示されることを確認
 * 4. 完了Toast「✅ 完了！ N件をインポートしました」が表示される
 * 5. 📋 TWEETSシートが作成され、データが書き込まれていることを確認
 * 6. 各列が正しいフォーマットで入っていることを確認:
 *    - A列: 日付 (YYYY-MM-DD)
 *    - B列: 時刻 (HH:MM)
 *    - C列: 本文
 *    - D列: 種別（Original/Reply/Retweet/Quote）
 *    - E列: いいね数（数値）
 * 期待結果: 全ツイートが正しくインポートされる
 */

/**
 * 【TC-04】bookmark.js インポート（正常系）
 * 1. Xのデータアーカイブから bookmark.js を準備する
 * 2. ファイル選択で bookmark.js を選んでインポート
 * 3. 🔖 BOOKMARKSシートが作成され、データが書き込まれていることを確認
 * 4. F列（カテゴリ）がプルダウン（データバリデーション）になっていることを確認
 * 期待結果: ブックマークが正しくインポートされ、カテゴリ入力がプルダウンで可能
 */

/**
 * 【TC-05】ダッシュボード自動更新
 * 1. インポート完了後、📊 DASHBOARDシートが作成されていることを確認
 * 2. 以下のスコアカードが正しい数値で表示されていることを確認:
 *    - 総ツイート数
 *    - 総いいね数
 *    - アクティブ期間
 *    - 総ブックマーク数
 * 3. 各グラフが正しく描画されていることを目視確認:
 *    - 月間投稿トレンド（折れ線）
 *    - ツイート種別構成（積み上げ横棒）
 *    - トップいいねツイート（横棒）
 * 期待結果: 全グラフが正しいデータで表示される
 */

/**
 * 【TC-06】時間帯ヒートマップ
 * 1. DASHBOARDの時間帯ヒートマップを確認
 * 2. セルの色が濃い＝ツイート数が多いことを目視確認
 * 3. 自分のツイート傾向と合致しているか確認（例: 夜型の人は夜のセルが濃い）
 * 期待結果: ヒートマップがツイート傾向を正しく表現している
 */

/**
 * 【TC-07】フィルタビュー機能（TWEETSシート）
 * 1. 📋 TWEETSシートを開く
 * 2. フィルタビューを作成し、種別で絞り込みができることを確認
 * 3. いいね数の降順ソートができることを確認
 * 4. 期間指定フィルターが機能することを確認
 * 期待結果: フィルタリングとソートが正しく機能する
 */

/**
 * 【TC-08】ブックマークカテゴリ設定
 * 1. 🔖 BOOKMARKSシートを開く
 * 2. 任意の行のF列（カテゴリ）でプルダウンが表示されることを確認
 * 3. デフォルトカテゴリが選択可能であることを確認:
 *    - 🟦 投資
 *    - 🟩 技術・AI
 *    - 🟨 雑学・教養
 *    - 🟧 仕事術
 *    - 🟪 趣味・エンタメ
 * 4. ⭐重要度（G列）のプルダウン（⭐1〜3）が機能することを確認
 * 5. ステータス（H列）のプルダウンが機能することを確認
 * 期待結果: 全てのプルダウンが正しく動作する
 */

/**
 * 【TC-09】手動ダッシュボード更新
 * 1. TWEETSシートのデータを一部編集する
 * 2. メニュー → 「🔄 ダッシュボード更新」を実行
 * 3. DASHBOARDの値が編集を反映して更新されることを確認
 * 期待結果: 手動更新が正しく機能する
 */

/**
 * 【TC-10】エラーハンドリング
 * 1. 不正なJSONファイルをアップロードする
 *    → エラーダイアログ「❌ JSONのパースに失敗しました」が表示される
 * 2. tweet.js 以外の形式のファイルをアップロードする
 *    → 適切なエラーメッセージが表示される
 * 3. 空の tweet.js をアップロードする
 *    → 正常終了し「0件をインポートしました」と表示される
 * 4. ファイルを選択せずに「インポート開始」を押す
 *    → アラート「ファイルを選択してください」
 * 期待結果: 全てのエラーケースでユーザーにわかりやすいメッセージが表示される
 */

/**
 * 【TC-11】大量データパフォーマンス（10,000件以上）
 * 1. 10,000件以上のツイートを含むデータを準備する
 * 2. インポートを実行し、6分以内に完了することを確認
 * 3. プログレスToastが定期的に更新されることを確認
 * 4. インポート完了後、DASHBOARDの表示が遅延なく行われることを確認
 * 5. フィルタビューの操作が快適であることを確認
 * 期待結果: 大量データでも実用的なパフォーマンスを維持する
 */

/**
 * 【TC-12】使い方ガイド表示
 * 1. メニュー → 「📖 使い方ガイド表示」をクリック
 * 2. サイドバーが表示されることを確認
 * 3. 以下の内容が含まれていることを確認:
 *    - 初回セットアップ手順
 *    - 各シートの説明
 *    - インポート手順
 * 期待結果: ガイドが正しく表示される
