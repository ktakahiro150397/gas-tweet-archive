📖 X Archive Tools 使い方ガイド

📥 データをインポートする

1
Xからデータをダウンロード

Xの設定 → 「あなたのアカウント」 → 「データのダウンロード」をリクエスト。準備ができたらzipで送られてきます。

2
zipを解凍してファイルを取り出す

解凍すると data/ フォルダの中に tweet.js（全ツイート履歴）と bookmark.js（ブックマーク）があります。

3
メニューからインポート

メニュー「📊 X Archive Tools」 → 「📥 データをインポート」をクリック。ファイルを選んで「インポート開始」を押すだけ。

📊 各シートの見かた

  • 📊 DASHBOARD 全体のサマリー表示。グラフとスコアカードでツイート傾向を一目で把握できます。
  • 📋 TWEETS 全ツイートの一覧。フィルタビューで「Replyだけ」「いいね数順」などに絞り込めます。
  • 🔖 BOOKMARKS 保存したブックマークの一覧。カテゴリや重要度を設定して整理できます。
  • 🏷️ CATEGORIES ブックマークのカテゴリを自由に追加・編集できます。
  • 👤 AUTHORS よく絡む人ランキング。リプライ送信数やブックマーク数で表示。
  • 🔍 SEARCH キーワード検索。期間や種別で絞り込んでツイートを探せます。

💡 Tips

📌 データは消えません
インポートしたデータはこのスプレッドシート内だけに保存されます。Xのデータが消えても大丈夫。

🔄 ダッシュボード更新
データを編集した後はメニュー → 「🔄 ダッシュボード更新」でグラフを再計算できます。

📁 対応ファイル
tweet.js（全ツイート履歴） / bookmark.js（ブックマーク） / tweets.json / bookmarks.json に対応しています。
