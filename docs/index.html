🎯 できること

📥

ファイル選択するだけの簡単インポート

Google Drive にアップロード不要。ダイアログから tweet.js を選ぶだけで全ツイート履歴をスプレッドシートに取り込みます。

📊

ダッシュボードで一発可視化

月間投稿トレンド、ツイート種別構成比、いいねランキング、曜日アクティビティ — 全グラフが自動生成されます。

🌡️

時間帯ヒートマップ

いつツイートする傾向があるか？を曜日×時間帯のマトリックスで色分け表示。朝型か夜型かが一目でわかります。

🔖

ブックマーク整理

bookmark.js もインポート可能。カテゴリ分け・重要度設定・ステータス管理で「保存したまま見返さない問題」を解決。

👤

誰とよく絡むか分析

リプライ送信数・ブックマーク数から、自分が最もインタラクションしているアカウントをランキング表示。

💰

買い切り ¥980（予定）

月額課金なし。Google アカウントさえあれば使えます。データは自分の Google Drive の中だけで完結。

📖 使い方（3ステップ）

1

X からデータをダウンロード

Xの設定 → 「あなたのアカウント」 → 「データのダウンロード」をリクエスト。zipで送られてくるので解凍します。

2

スプレッドシートでインポート

スプレッドシートを開き、メニューから「📥 データをインポート」→ tweet.js を選択。自動で全ツイートが読み込まれます。

3

ダッシュボードを眺める

完了したら📊 DASHBOARD シートに移動。グラフや数値で自分のツイート傾向を好きなだけ分析できます。
